# Guia do Utilizador - Menús Jindungo

Bem-vindo ao Menús Jindungo! Este guia vai ajudar-te a configurar e gerir o teu restaurante de forma profissional.

## 1. O Teu Painel de Controlo (Dashboard)
Ao entrar, verás o resumo das tuas vendas, pedidos ativos e o estado do teu restaurante.
- **Botão Loja Aberta/Fechada:** Controla se os clientes podem ou não fazer pedidos no teu menu.

## 2. Gestão do Menu Digital
No menu lateral, clica em **"Menu Digital"**:
- **Categorias:** Cria secções como "Entradas", "Pratos Principais" ou "Bebidas".
- **Produtos:** Adiciona os teus pratos, fotos, preços e descrições.
- **Stock:** Podes ativar o controlo de stock para que um prato desapareça automaticamente quando esgotar.

## 3. Configurações e Estilo
Clica em **"Configurações"**:
- **Personalização:** Aqui podes escolher a cor principal do teu menu e o tipo de letra. As mudanças aparecem no menu do cliente no mesmo segundo!
- **Taxas de Entrega:** Podes escolher cobrar por bairro (Manual) ou por KM (Automático). Lembra-te de marcar a localização do teu restaurante no mapa para o cálculo automático funcionar.

## 4. Gestão de Pedidos (A Tua Cozinha)
A secção mais importante é a **"Pedidos (Cozinha)"**:
- Aqui verás os pedidos a entrar com um som de alerta.
- **Botão Preparar:** Avisa o sistema que o prato está a ser feito.
- **Botão Pronto:** Avisa o cliente (via WhatsApp ou App) que o pedido pode ser levantado ou vai ser entregue.
- **Ajustar Taxa:** Se precisares de mudar o valor da entrega num pedido específico, usa o botão dourado no cartão do pedido.

## 5. Marketing e Fidelização
- **Cupões:** Cria códigos de desconto (ex: JINDUNGO10) para os teus clientes usarem no checkout.
- **Cartão Fidelidade:** Configura quantos pedidos o cliente precisa de fazer para ganhar um prémio automático.

## 6. Dicas para o Sucesso
- Usa fotos de alta qualidade; os clientes "comem com os olhos".
- Mantém o teu número de WhatsApp sempre atualizado nas configurações para receberes notificações.
- Imprime o teu QR Code (disponível no painel) e coloca-o em cada mesa.
